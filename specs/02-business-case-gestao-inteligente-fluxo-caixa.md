# SPEC 02 — Business Case | Gestão Inteligente do Fluxo de Caixa

## Objetivo

Implementar a primeira versão completa da página `/cases/gestao-inteligente-fluxo-caixa`, com uma narrativa executiva focada na transformação do processo financeiro da empresa fictícia HealthOne.

## Escopo implementado

- Hero e identificação do Case 01;
- contexto da empresa e uso do TOTVS;
- diagnóstico dos problemas;
- pergunta de negócio e informações prioritárias;
- objetivos do projeto;
- metodologia em cinco etapas;
- indicadores estratégicos e decisões apoiadas;
- tecnologias utilizadas;
- roadmap das próximas etapas;
- acesso ao Case a partir da Home.

## Fora do escopo

Não foram implementados regras de negócio, automações, integrações, dashboards, banco de dados ou backend.

## Critérios de aceite

- [x] Página responsiva;
- [x] identidade visual consistente com a Home;
- [x] componentes reutilizáveis;
- [x] hierarquia visual executiva;
- [x] nenhuma funcionalidade de negócio;
- [x] estrutura preparada para os próximos módulos.
